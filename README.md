# Zellianah Jayne Mendoza: About Me

My personal profile page for MMS 171 (UP Open University), published with GitHub Pages.

## Files

| File | What it does |
| --- | --- |
| `index.html` | Page content and structure |
| `style.css` | Typography, colors, layout, responsive rules |
| `images/` | Web-sized photos |

## Design notes

- **Headings:** Unbounded (600/700), red-to-maroon gradient text. Wide and rounded, so my name reads like a signature.
- **Body, subheadings, navigation:** Urbanist (400/600/700). Small uppercase, letter-spaced labels mark navigation, dates, and contact types.
- **Palette:** apple red to maroon, with sage and grass greens, on a warm paper background.
- Built with HTML and CSS only (no JavaScript). Respects "reduce motion" settings, and is keyboard accessible (skip link, visible focus).
